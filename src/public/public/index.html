Method

Three passes. Each one has to survive the next.

Nothing reaches your report because a model was confident. It reaches your report because something re-checked it, or because it is labelled as a judgment call you still have to make.

01 / Measured

Prove what a machine can prove

axe-core, the Chrome accessibility tree, a real keyboard trace, and computed contrast — the value the browser actually rendered, not the value the CSS declared.

facts · confidence 1.0
02 / Assessed

Ask AI only what machines get wrong

Alt-text quality, link and heading semantics, form errors, reading order. Grounded in WCAG and ARIA source text — never in the model's own earlier guesses.

judgment calls · tagged as such
03 / Verified

Re-test the fix before calling it one

Corrected HTML, ARIA and CSS injected into a fresh browser and re-scanned. Resolved with no new violations — or it stays labelled a suggestion.

verified, or honestly unverified
